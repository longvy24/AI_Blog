Five Stacks In A Year.
I Chose None Of Them.

The honest ranking, after a year of AI tools I didn't pick. The same deck test on each, top to bottom — and why the best one I used isn't the one I'm on now.

The 22-second version · Stage 5 of 5 · The finale

Last stage, and here's the number it turns on: four. Four tries to get a single deck out of the stack I'm on now — Grok, running in Cursor — and it's still rough. Not four-then-nailed-it. Four, and the result is fine, not great.

Line that up against the rest of the volume and the whole arc fits in three numbers. GitHub Copilot: ten attempts, never landed. Claude Code: one, clean. Grok in Cursor: four, still rough. Same task, three stacks — and I chose exactly none of them.

The cost wall
The tool that did it in one
got expensive.

That's the entire cost story and I'm going to leave it there — the figures aren't mine to publish and the decision was never mine to make. What I can give you is the shape of it: the best tool I used got used enough to get expensive, and cost follows usage. So I'm on Grok now, learning Cursor. It reads less from context than what I left, so I've had to spell out what I want — and, louder, what I don't.

// Disclosure, before the ranking

The bias up front: Claude Code built this channel, its videos, and this blog. It sits at number one below, so read that with the obvious conflict in mind. I've tried to rank on how each tool served my actual work, not on which one I'm loyal to — but you should know the loyalty exists.

The Payoff

The Honest Ranking, One To Five

01Most versatile
Claude Code
The most capable of everything I used. It thinks its way through a request instead of just running it — the one that took a single attempt at the deck the others fought for ten. Number one, and yes, it's the one that built this.
02Gets it done
Cursor + Grok
The stack I'm on now. Capable, if less intuitive — like a genie: ask for one thing, get four. It works; it just needs everything spelled out, and it needs to be told what not to do as clearly as what to.
03Analysis & HTML
GitHub Copilot
Strong at analysis and at HTML decks; weak at the .pptx it can't watch itself render. Good inside its lane — and the lane is narrower than the marketing makes it look. (The full breakdown is Stage 4.)
04Work only
The In-House Tool
The internal tool. Useful inside the job it was built for — but not something I can point at my own projects, so it ranks here on scope of my use, not on any verdict about how it was built.
05No critique
ChatGPT
The one I stopped using. It kept handing back the positive answer instead of the true one — agreement where I needed a critique. A yes-man is worse than no tool at all when the thing you need is to be told you're wrong.
// What five eras taught me

Five stacks in about a year, not one of them my decision. If there's a single lesson under all five, it's this: the tool is never the asset. What you've accumulated is, and what you've learned is. Keep both portable and the next change someone makes for you costs a week instead of a quarter.
