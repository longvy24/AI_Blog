10 Prompts for When
AI Writes Code You Can’t Debug

I can’t code — so when the thing AI built breaks, I can’t just open the file and see the problem. These are the ten prompts I run instead of guessing.

R
Ryu Vy
AIToolsDaily24 · By a human, for humans

AI wrote the code — that’s the whole point of building this way. You describe what you want and it hands you something that runs. Right up until it doesn’t.

And when it breaks you’re stuck, because you can’t just open the file and spot the bug in code you didn’t write. These ten prompts are how you debug something you can’t read — copy-paste, in the order you’d actually reach for them.

The Ten

Every Fix, Copy-Paste Ready

01 / 10Locate
Read It Back to Me
"Explain this error in plain English. What broke, where, and why — before you fix it."
You can’t fix what you can’t name. Translation first, patch second.
02 / 10Narrow
Cut It in Half
"Delete everything not needed to reproduce this. Give me the smallest version that fails."
A 400-line file has 400 suspects. A 20-line one has three.
03 / 10Prove
Fail First
"Before fixing, write the test that fails. Then fix it."
A fix you can’t prove is a guess that happens to run.
04 / 10Isolate
One Change at a Time
"Change exactly one thing. Tell me what you changed and what you expect."
Two changes at once and the result teaches you nothing.
05 / 10Log
Print the Real Values
"Add a log line before and after the failing step. Show me the actual values."
What you assume the data is, and what it is, are rarely the same.
06 / 10History
What Did You Touch
"List every file you edited in the last step. What could that have broken?"
Most ‘random’ bugs were introduced two prompts ago.
07 / 10Revert
Go Back to Working
"Undo everything since the last version that ran. Start again from there."
Debugging forward from broken is slower than restarting from working.
08 / 10Fence
Don't Touch Anything Else
"Fix only this function. Change nothing else. List every edit you made."
A fix that rewrites four files is a new bug with extra steps.
09 / 10Ask
Make It Ask You
"What do you need to know from me to fix this? Ask before you write code."
Half of AI’s wrong fixes are answers to a question it guessed.
10 / 10Close
Why Did It Happen
"It works now. In two sentences: what was actually wrong?"
The explanation is the part you keep. The code you’ll regenerate anyway.
