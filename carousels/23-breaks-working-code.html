9 Prompts to Stop
AI Breaking Code That Worked

The bug I hate most isn't the one it can't fix. It's the one it fixes while quietly rewriting three things that were fine.

The bug I hate most isn't the one the model can't fix. It's the one it fixes while quietly rewriting three other things that were completely fine — the ones you don't notice until they break later.

“While I was in there” is where working code goes to die. These nine prompts fence the change so a fix stays a fix. Copy-paste.

The Nine

Every Guardrail, Copy-Paste Ready

01 / 09Scope
Fence the Change
"Only touch the function I named. If the fix needs anything else, ask first."
Unfenced, it treats your whole file as a first draft.
02 / 09Diff
Show Me What Changed
"List every line you changed and why, before you give me the file."
You can read a nine-line list. You cannot read a 400-line rewrite.
03 / 09Baseline
Lock the Behaviour
"Write down what works now. Anything that stops working is a bug you caused."
Regressions hide because nobody wrote down what working meant.
04 / 09Minimal
Smallest Possible Fix
"Give me the smallest change that fixes this. Not the cleanest — the smallest."
“While I was in there” is where working code goes to die.
05 / 09Rollback
Keep the Old Version
"Leave the original commented above the change so I can put it straight back."
The fastest fix for a bad fix is the line you just deleted.
06 / 09Setup
Don't Touch the Deps
"Do not add, remove or reorder any import, config value or dependency."
Half of “it worked yesterday” is a package it swapped without telling you.
07 / 09Naming
Keep Every Name
"Keep all existing names exactly. Rename nothing, even if the name is wrong."
One rename you didn't notice breaks three files you didn't open.
08 / 09Test
Break It On Purpose
"Give me one input that should fail and one that should pass. Predict both."
A prediction it gets wrong tells you more than a test that passes.
09 / 09Stop
Say When You're Guessing
"If you're not sure this is the cause, say so instead of changing something."
It would rather edit than admit. Give it permission not to.
