9 Prompts to Stop
AI Building the Wrong Thing

The worst AI builds aren’t the broken ones — they’re the ones that run perfectly and solve the wrong problem. Nine prompts that catch it before you’ve sunk an afternoon in.

R
Ryu Vy
AIToolsDaily24 · By a human, for humans

The worst AI builds aren’t the broken ones. They’re the ones that run perfectly and solve the wrong problem — because the model quietly filled a gap you didn’t know you’d left.

Stopping that is a front-loading job: pin the spec, surface the assumptions, and make it show you the plan before it writes a line. Nine prompts that catch the wrong build while it’s still cheap to change.

The Nine

Every Guardrail, Copy-Paste Ready

01 / 09Spec
Say It Back First
"Before you build: describe what you think I asked for, in your own words."
Thirty seconds of read-back beats an hour of the wrong app.
02 / 09Plan
Plan First, Code Later
"Give me the file list and what each one does. No code until I say go."
A plan is cheap to reject. A finished codebase is not.
03 / 09Scope
Smallest Version Only
"What's the least you can build that proves this works? Build only that."
v1 should be slightly embarrassing. That’s how you find out fast.
04 / 09Assume
List What You Guessed
"List every assumption you made that I didn't actually state."
The guesses are exactly where the wrong thing hides.
05 / 09Stop
Ask Before You Add
"If you're about to add something I didn't ask for, ask me first."
‘Helpful extras’ are the number one source of scope creep.
06 / 09Exclude
Name the Not-Now
"Not now: [list]. Don't build it, don't stub it, don't mention it again."
Naming the no is far faster than deleting the yes.
07 / 09Check
Halfway Checkpoint
"Stop at 50%. Show me what runs so far before you continue."
Catching a misread at half costs you half the rework.
08 / 09User
Who Clicks This First
"Describe the one person who uses this, and what they click first."
A build with no user in mind becomes a build with every feature.
09 / 09Done
Define Finished
"Write the three things that must be true for this to be done."
Without a finish line the model will happily build forever.
